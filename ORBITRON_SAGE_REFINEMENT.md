Section title bars are filled sage #a9bfa0 with rounded corners and dark #383a36 cut-out lettering. Inline Delay/Reverb labels on those bars use the same dark text for contrast; existing buttons remain readable and operable.

Every control section now uses the oscillator's #383a36 face and identical material layers; the keyboard housing matches. Parameter labels, controls, black leads, key textures and the working arp remain intact.

CSS-only product changes. Every embedded program script is byte-identical to the working rollback. Existing Chromium geometry, header, control, patch and Worklet/fallback arp/audio checks passed, including both target sizes with keyboard shown/hidden.
